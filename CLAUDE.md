## Project Overview

Documentation site for MycroCloud, built with Docusaurus 3.1.1 (React 18, TypeScript). Production URL: https://docs.mycrocloud.com

## Commands

- `yarn start` — Local dev server with hot reload
- `yarn build` — Production build to `build/` directory
- `yarn typecheck` — Run TypeScript type checking (`tsc`)
- `yarn clear` — Clear Docusaurus cache

## Architecture

- **docs/** — Markdown documentation organized by topic (routing, functions). Sidebar is auto-generated from folder structure (`sidebars.ts` uses `autogenerated` with `dirName: '.'`).
- **src/pages/** — Custom React pages (homepage at `index.tsx`)
- **src/components/** — Shared React components (e.g., `HomepageFeatures`)
- **src/css/custom.css** — Global CSS overrides
- **docusaurus.config.ts** — Site config (navbar, footer, theme, prism syntax highlighting)
- **static/** — Static assets served at site root (images, favicon)

## Key Configuration

- Blog is disabled (`blog: false` in docusaurus.config.ts)
- Broken links throw errors (`onBrokenLinks: 'throw'`) — all internal doc links must be valid
- Uses `@docusaurus/preset-classic` with Prism themes (github light, dracula dark)
- Package manager: yarn
- Node requirement: >=18.0
